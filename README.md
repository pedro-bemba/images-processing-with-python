# Processamento de Imagens com Python

Este projeto fornece um ambiente completo para processamento e análise de imagens utilizando Python. O conjunto de bibliotecas instalado permite desde manipulações básicas até operações avançadas com imagens digitais.

## 📦 Tecnologias e Bibliotecas

O projeto utiliza as seguintes bibliotecas:

| Biblioteca      | Versão | Finalidade                                       |
|----------------|--------|--------------------------------------------------|
| `jupyterlab`    | Última | Ambiente interativo para notebooks               |
| `numpy`         | Última | Operações matriciais e manipulação de arrays     |
| `matplotlib`    | Última | Visualização de imagens e gráficos               |
| `scikit-image`  | Última | Algoritmos avançados de processamento de imagens |
| `ipympl`        | Última | Gráficos interativos no Jupyter                  |
| `imageio`       | Última | Leitura e escrita de diferentes formatos de imagem |
